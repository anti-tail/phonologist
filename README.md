# phonologist

自律分節音韻論の連結図（音調と拍・音節などを線で結んだ図）をブラウザで組み、SVG や PNG で保存するためのページです。

https://anti-tail.github.io/phonologist/

## 書き方

```
label: (1)
T: H L
S: *い の ち
link: 1-1 2-2,3
gloss: 命 *inoti*
->
T: L H
S: ba la ma
link: 1-1 2-2 2~3
```

- 1 行に 1 つの層を上から順に書きます。`名前: 要素 要素 …`
- `link:` の行に連結を書きます。`1-2` は上の層の 1 番目と下の層の 2 番目をつなぎます。`2-2,3` のようにまとめて書けます。
- 線の種類は `-` 実線、`~` 破線、`.` 点線、`x` 切断の印です。
- 3 層以上のときは `μ1-S1` のように層の名前を添えます。名前のない連結は 1 層目と 2 層目の間とみなします。
- 要素の頭に `*` を付けると上にアクセントの印が付きます。`(H)` は丸囲み、`_` は何も書かない位置です。
- `->` の行で次の図に移ります。`-> 規則名` で矢印の上に文字を添え、`=>` で二重の矢印になります。
- `label:` で左に番号、`gloss:` で下に語釈を添えます。`*…*` は斜体になります。
- プレビューで要素を 2 つ順にクリックすると、その間の線が 実線、破線、切断、なし の順に切り替わります。

## 保存

- PNG は 2〜6 倍の解像度で保存できます。
- SVG は、図に使った文字の分だけフォントを埋め込んで保存します。ブラウザではそのまま同じ見た目で表示されます。Illustrator や Inkscape など埋め込みフォントを読まないソフトでは、同じフォントを端末に入れておいてください。
- 共有用リンクには入力内容と見た目の設定が入ります。

## つくり

ビルドの要らない静的ページです。`engine.js` が入力の読み取り、配置、SVG と Canvas への描画を受け持ち、`app.js` が画面の操作を受け持ちます。フォントは Google Fonts（Charis SIL、Gentium Book Plus、Noto Serif / Sans、Noto Serif JP / Sans JP、しっぽり明朝、BIZ UDP明朝 / ゴシック、クレー）を使います。
